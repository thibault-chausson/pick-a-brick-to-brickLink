Pick a Brick → XML BrickLink

Colle ton export CSV Pick a Brick, l'outil interroge l'API Rebrickable pour retrouver les références BrickLink correspondantes et génère un fichier d'import d'inventaire prêt pour BrickLink. Tout se passe dans ton navigateur, rien n'est envoyé ailleurs qu'à Rebrickable.

1. Clé API Rebrickable

Générée depuis ton compte Rebrickable, page Settings → API. Elle reste uniquement dans ce navigateur, en mémoire le temps de la session : elle n'est jamais écrite dans le XML ni stockée sur disque.

2. CSV Pick a Brick

La colonne error est ignorée : elle vient de Pick a Brick et ne sert pas à la conversion.

0 réussies 0 en erreur 0 au total

3. Détail des conversions

4. XML d'inventaire BrickLink

Les lignes dont la pièce, la couleur ou la correspondance BrickLink ne sont pas trouvées sur Rebrickable sont marquées en erreur et exclues du XML — aucune correspondance n'est devinée. Les requêtes sont envoyées une par une avec un court délai pour respecter les limites de l'API Rebrickable.
